# 表型、尺度与世界坐标冻结协议

协议版本：`v0.1.0-phase0`

## 1. 基本原则

1. 同一字段在所有数据源中必须具有相同语义、单位和端点定义；
2. 公开数据提供的相似名称表型，只有定义相同才能合并；
3. 模型输出、人工测量和点云派生量必须分别保存`label_source`；
4. 主要结论以植株/冠层级输出为主，叶片级仅评价明确可见且具有稳定身份的抽样功能叶；
5. 所有正式评价最终使用厘米或平方厘米，原始数据仍保留原单位。

## 2. 世界坐标系

统一右手坐标系：

- 原点：目标植株根际地面点，或plot参考地面平面的指定原点；
- `+z`：与重力反方向一致；
- `+x`：沿作物行正方向；
- `+y`：垂直作物行，满足右手系；
- 地面平面：`z=0`。

坐标来源优先级：

1. 已标定平台坐标系 + IMU重力 + plot行向；
2. RTK/GCP/已知相机外参 + 地面平面；
3. 点云RANSAC地面 + 人工记录行向；
4. 受控转台数据使用机器人世界坐标，并记录其与重力方向的变换。

如果地面不可见，必须将`ground_source`记录为`imu`、`plot_edge`、`empty_ground_reference`、`known_camera_height`或`manual_control_points`，不得默认为最低点。

## 3. 株高

正式字段：`plant_height_cm`

定义：从局部地面平面到目标植株最高结构端点，沿`+z`方向的垂直距离。

必须同时记录：

- `height_endpoint_policy`；
- `ground_source`；
- `include_reproductive_organs`；
- `include_awn`；
- 是否存在倒伏、折断或离群叶尖。

推荐默认端点：

- 非禾本科：最高完整活体器官点；
- 禾本科有穗期：穗顶，默认不含芒；
- 营养生长期：最高完整叶尖。

同一实验内不得混用端点策略。跨作物汇总时按`height_endpoint_policy`分层。

解析基线同时输出：

- `height_p95_cm`；
- `height_p99_cm`；
- `height_max_filtered_cm`。

这些解析量不能自动替代人工`plant_height_cm`，应在训练集上选择或由Head学习残差。

## 4. 冠幅与冠层投影

正式字段：

- `canopy_width_row_cm`：沿行方向`x`的稳健跨度；
- `canopy_width_cross_row_cm`：垂直行方向`y`的稳健跨度；
- `canopy_max_width_cm`：地面投影中方向无关的最大稳健跨度；
- `canopy_projected_area_cm2`：去除小连通域和离群点后的冠层投影面积。

人工测量采用两条正交方向，必须记录方向来源。点云解析默认使用1%–99%分位跨度，完整min–max只作为附加量。

离群叶处理规则：

- 完整且属于目标植株的真实叶片保留；
- 断叶、邻株误分、单点噪声和面积低于阈值的孤立组件剔除；
- 剔除规则、点比例和阈值必须保存。

## 5. 可见功能叶长度

正式字段：`leaf_length_cm`

定义：从叶片基部/叶鞘连接处到叶尖，沿三维中脉或中心线的弧长。

禁止：

- 使用基部到叶尖的欧氏直线距离替代；
- 对没有稳定leaf ID的全局回归值解释为逐叶长度；
- 将展开后人工测量与自然卷曲状态的图像派生长度混为同一种标签。

必须记录：

- `leaf_uid`与`leaf_obs_id`；
- 叶位或叶序；
- 可见比例；
- 自然卷曲、破损与遮挡；
- 人工测量是否展开叶片；
- 中心线来源。

## 6. 可见功能叶宽度

正式字段：`leaf_width_cm`

定义：沿三维中心线搜索，在近似垂直局部中心线的截面方向取得最大有效宽度。

必须同时记录最大宽度相对位置：

`leaf_width_position_ratio = distance(base, width_location) / leaf_length`

宽度有效范围为`[0, leaf_length]`。严重卷曲导致截面不可观测时，`measurable=false`，不得强制填入零值。

## 7. 可测性与可见性

`visibility_ratio`定义为该器官在全部有效视角中可观测表面/预计完整表面的估计比例，取值`[0,1]`。

正式叶片评价默认门槛：

- `visibility_ratio >= 0.60`；
- 基部和叶尖均至少在一个有效视角可识别；
- 中心线有效覆盖不低于80%；
- `leaf_match_status=confirmed`；
- `measurable=true`。

低于门槛的样本可以用于可测性分类训练，但不能进入叶长宽主精度指标。

## 8. plot级聚合

每个plot至少输出：

- 株高均值、中位数、P90、P95和变异系数；
- 双向冠幅均值、中位数和置信区间；
- 冠层覆盖率与投影面积；
- 可见抽样功能叶长宽的均值、中位数、分位数和有效样本数；
- 不可测、重采和人工复核比例。

叶片统计必须使用`n_visible_measurable_leaves`作为分母，不得暗示覆盖全部叶片。

## 9. 标签来源与优先级

优先级仅用于训练权重，不代表可以混为同一评价集：

1. `manual_repeated`；
2. `tls_lidar`；
3. `scanner_derived`；
4. `pointcloud_derived`；
5. `image_derived`；
6. `model_pseudo_label`。

同一表型存在多来源时分别保存，不覆盖原始值。

## 10. 测量重复性

尺度精测子集及至少10%的人工表型样本执行双人或重复测量，保存：

- 重复次数；
- 测量者；
- 仪器；
- 均值；
- 标准差；
- 最大差值；
- 裁决值与裁决理由。
